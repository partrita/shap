24  간단한 OR 함수 설명

이 노트북에서는 SHAP 값을 사용하여 OR 함수를 설명하는 방법을 살펴봅니다. 이 예를 통해 우리는 배경 분포 변경이 TreeExplainer에서 얻은 설명에 어떤 영향을 미치는지 이해합니다.

이는 ‘is_young’ 및 ’is_female’이라는 두 가지 특성이 포함된 간단한 예를 기반으로 하며, 대피 시 여성과 어린이에게 우선권이 주어져 생존 가능성이 더 높았던 타이타닉 생존 데이터세트에서 대략 동기를 부여받았습니다. 이 시뮬레이션된 예에서는 이 효과가 극단적으로 적용되어 모든 어린이와 여성이 생존하고 성인 남성은 생존하지 못합니다.

import numpy as np
import pandas as pd
import xgboost
from IPython.display import display

import shap

rng = np.random.default_rng(42)

24.1 OR 함수에 따른 데이터세트 생성

N = 40_000
M = 2

# randomly create binary features for `is_young` and `is_female`
X = (rng.standard_normal(size=(N, 2)) > 0) * 1
X = pd.DataFrame(X, columns=["is_young", "is_female"])

# force the first sample to be a young boy
X.loc[0, :] = [1, 0]
display(X.head(3))

# you survive (y=1) only if you are young or female
y = ((X.loc[:, "is_young"] + X.loc[:, "is_female"]).to_numpy() > 0) * 1
is_young is_female
0 1 0
1 1 1
2 0 0

24.2 이 OR 기능을 모방하기 위해 XGBoost 모델을 훈련시킵니다.

model = xgboost.XGBRegressor(n_estimators=100, learning_rate=0.1, random_state=3)
model.fit(X, y)
model.predict(X)
array([9.9998671e-01, 9.9998671e-01, 1.3295135e-05, ..., 9.9998671e-01,
       9.9998671e-01, 9.9998671e-01], dtype=float32)

24.3 어린 소년에 대한 예측을 설명합니다

24.3.1 백그라운드 배포를 위한 훈련 세트 사용

아래 예시 설명에서 is_young = True는 양수 값(모델 출력이 증가하여 생존 예측이 증가함을 의미)을 갖는 반면, is_female = False는 음수 값(모델 출력이 감소함을 의미)을 갖습니다. 누군가는 그 사람이 젊다는 것을 이미 알고 있기 때문에 ’is_female = False’가 영향을 미치지 않아야 한다고 주장할 수 있지만, SHAP 값은 다른 특성을 반드시 알 필요가 없는 경우에도 특성이 갖는 영향을 설명하므로 ’is_female = False’는 여전히 예측에 부정적인 영향을 미칩니다.

explainer = shap.TreeExplainer(model, X, feature_perturbation="interventional")
explanation = explainer(X.loc[[0], :])

# for the young boy:
expected_value = explanation.base_values[0]
shap_values = explanation.values[0]

print(f"explainer.expected_value: {expected_value:.4f}")
print(f"SHAP values for (is_young = True, is_female = False): {shap_values.round(4)}")
print("model output:", (expected_value + shap_values.sum()).round(4))
explainer.expected_value: 0.7600
SHAP values for (is_young = True, is_female = False): [ 0.385 -0.145]
model output: 1.0

위와 동일한 정보이지만 폭포 플롯으로 시각화되었습니다.

# waterfall plot for the young boy (background distribution => training set)
shap.plots.waterfall(explanation[0])

24.3.2 배경 분포에 부정적인 예시만 사용하기

이 두 번째 설명 예제의 요점은 다른 배경 분포를 사용하여 입력 기능 간의 크레딧 할당을 어떻게 변경할 수 있는지 보여주는 것입니다. 이는 이제 사망한 사람(성인 남성)과 비교하여 기능의 중요성을 비교하고 있기 때문에 발생합니다. 죽은 사람과 어린 소년의 유일한 차이점은 그 소년이 어리다는 점입니다. 따라서 모든 공로는 ‘is_young = True’ 기능에 있습니다.

이는 잘 정의된 배경 그룹을 사용할 때 설명이 더 명확해지는 경우가 많다는 점을 강조합니다. 이 경우 설명을 “이 샘플이 일반 샘플과 어떻게 다른지”에서 “이 샘플이 죽은 사람들과 어떻게 다른지”(즉, 왜 살았습니까?)로 변경됩니다.

explainer = shap.TreeExplainer(
    model,
    X.loc[y == 0, :],  # background distribution => non-survival
    feature_perturbation="interventional",
)
explanation = explainer(X.loc[[0], :])

# for the young boy:
expected_value = explanation.base_values[0]
shap_values = explanation.values[0]

print(f"explainer.expected_value: {expected_value:.4f}")
print(f"SHAP values for (is_young = True, is_female = False): {shap_values.round(4)}")
print("model output:", (expected_value + shap_values.sum()).round(4))
explainer.expected_value: 0.0000
SHAP values for (is_young = True, is_female = False): [1. 0.]
model output: 1.0
# waterfall plot for the young boy (background distribution => non-survival)
shap.plots.waterfall(explanation[0])

24.3.3 백그라운드 분포에 긍정적인 예만 사용

배경 분포에 대해 긍정적인 예만 사용할 수도 있으며 모델의 예상 출력(배경 분포 아래)과 어린 소년의 현재 출력 간의 차이가 0이므로 SHAP 값의 합도 0이 됩니다.

explainer = shap.TreeExplainer(
    model,
    X.loc[y == 1, :],  # background distribution => survival
    feature_perturbation="interventional",
)
explanation = explainer(X.loc[[0], :])

# for the young boy:
expected_value = explanation.base_values[0]
shap_values = explanation.values[0]

print(f"explainer.expected_value: {expected_value:.4f}")
print(f"SHAP values for (is_young = True, is_female = False): {shap_values.round(4)}")
print("model output:", (expected_value + shap_values.sum()).round(4))
explainer.expected_value: 1.0000
SHAP values for (is_young = True, is_female = False): [ 0.14 -0.14]
model output: 1.0
# waterfall plot for the young boy (background distribution => survival)
shap.plots.waterfall(explanation[0])

24.3.4 배경배포에 젊은 여성을 활용

샘플을 젊은 여성과 비교하면 성인 남성(data=(0, 0))을 제외하고는 두 기능 모두 중요하지 않습니다. 이 경우 두 기능 모두 사망에 대해 동일한 공로를 인정합니다(직관적으로 예상할 수 있음).

explainer = shap.TreeExplainer(
    model,
    np.ones((1, M)),  # background distribution => all young women
    feature_perturbation="interventional",
)
explanation = explainer(X.head(3))

print("Feature data:")
display(explanation.data)
print()
print("SHAP values:")
display(explanation.values.round(4))
Feature data:
array([[1, 0],
       [1, 1],
       [0, 0]])

SHAP values:
array([[ 0. , -0. ],
       [ 0. ,  0. ],
       [-0.5, -0.5]])
