37  단순 모델에 대한 트리 SHAP 이해

기능의 SHAP 값은 모든 기능 순서에 대해 한 번에 하나씩 기능을 도입할 때 해당 기능을 조건으로 하여 모델 출력의 평균 변화입니다. 이것은 말하기는 쉽지만 계산하기는 어렵습니다. 따라서 이 노트는 이것이 매우 작은 나무에 대해 어떻게 작용하는지 확인할 수 있는 몇 가지 간단한 예를 제공하기 위한 것입니다. 임의의 대형 트리의 경우 트리를 보고 이러한 값을 직관적으로 추측하는 것은 매우 어렵습니다.

import graphviz
import numpy as np
import pandas as pd
from sklearn.tree import DecisionTreeRegressor, export_graphviz

import shap

37.1 단일 분할 예시

# build data
N = 100
M = 4
X = np.zeros((N, M))
X.shape
y = np.zeros(N)
X[: N // 2, 0] = 1
y[: N // 2] = 1

# fit model
single_split_model = DecisionTreeRegressor(max_depth=1)
single_split_model.fit(X, y)

# draw model
dot_data = export_graphviz(
    single_split_model,
    out_file=None,
    filled=True,
    rounded=True,
    special_characters=True,
)
graph = graphviz.Source(dot_data)
graph

37.1.0.1 모델 설명하기

편향 항은 훈련 데이터 세트(0.5)에 대한 모델의 예상 출력입니다. 모델에 사용되지 않은 기능의 SHAP 값은 항상 0인 반면, \(x_0\)의 경우 예상 값과 모델 출력 간의 차이일 뿐입니다.

xs = [np.ones(M), np.zeros(M)]
df = pd.DataFrame()
for idx, x in enumerate(xs):
    index = pd.MultiIndex.from_product([[f"Example {idx}"], ["x", "shap_values"]])
    df = pd.concat(
        [
            df,
            pd.DataFrame(
                [x, shap.TreeExplainer(single_split_model).shap_values(x)],
                index=index,
                columns=["x0", "x1", "x2", "x3"],
            ),
        ]
    )

37.2 두 가지 기능과 예

이 예에서는 두 가지 기능을 사용합니다. 특성 \(x_{0} = 1\) AND \(x_{1} = 1\)인 경우 목표 값은 1이고 그렇지 않으면 0입니다. 따라서 우리는 이것을 AND 모델이라고 부릅니다.

# build data
N = 100
M = 4
X = np.zeros((N, M))
X.shape
y = np.zeros(N)
X[: 1 * N // 4, 1] = 1
X[: N // 2, 0] = 1
X[N // 2 : 3 * N // 4, 1] = 1
y[: 1 * N // 4] = 1

# fit model
and_model = DecisionTreeRegressor(max_depth=2)
and_model.fit(X, y)

# draw model
dot_data = export_graphviz(and_model, out_file=None, filled=True, rounded=True, special_characters=True)
graph = graphviz.Source(dot_data)
graph

37.2.0.1 모델 설명하기

편향 항은 훈련 데이터 세트(0.25)에 대한 모델의 예상 출력입니다. 사용되지 않는 기능 \(x_2\) 및 \(x_3\)에 대한 SHAP 값은 항상 0입니다. \(x_0\) 및 \(x_1\)의 경우 이는 예상 값(0.25)과 모델 출력 간의 차이일 뿐입니다(AND 기능에 동일하게 기여하므로).

xs = np.array([np.ones(M), np.zeros(M)])
# np.array([np.ones(M), np.zeros(M), np.array([1, 0, 1, 0]), np.array([0, 1, 0, 0])]   # you can also check these examples
df = pd.DataFrame()
for idx, x in enumerate(xs):
    index = pd.MultiIndex.from_product([[f"Example {idx}"], ["x", "shap_values"]])
    df = pd.concat(
        [
            df,
            pd.DataFrame(
                [x, shap.TreeExplainer(and_model).shap_values(x)],
                index=index,
                columns=["x0", "x1", "x2", "x3"],
            ),
        ]
    )

예 1의 Shap 값을 얻는 방법은 다음과 같습니다.
편향 항(y.mean())은 0.25이고 목표 값은 1입니다. 그러면 관련 특성 간에 분할되도록 1 - 0.25 = 0.75가 남습니다. \(x_0\) 및 \(x_1\)만이 목표 값에 (동일한 정도로) 기여하므로 둘 사이에 나누어집니다(즉, 각각 0.375).
