38  그림 1 - 단순한 불일치 예

여기서는 XGBoost가 Tree SHAP 논문의 그림 1에서 모델 A와 모델 B를 빌드하도록 합성 데이터를 생성합니다. 그런 다음 Tree SHAP 및 Saabas를 사용하여 개별화된 기능 중요도를 계산하고 Tree SHAP, 게인, 분할 개수 및 순열을 사용하여 전역 기능 중요도를 계산합니다.

import matplotlib.pyplot as pl
import numpy as np
import shap
import xgboost as xgb

38.1 모델 A 생성

이것은 왼쪽 하위 분할을 강제로 생성하기 위한 약간의 노이즈가 있는 간단한 AND 함수입니다. 기능 0은 발열이고 기능 1은 기침입니다.

N = 2000
X = np.zeros((N,2))
X[:1000,0] = 1
X[:500,1] = 1
X[1000:1500,1] = 1
yA = 80 * (X[:,0] * X[:,1]) + 1e-4 * ((X[:,0] == 0) * (X[:,1] == 0)) # last term forces the creation of left split
Xd = xgb.DMatrix(X)
# train a model with single tree
XdA = xgb.DMatrix(X, label=yA)
modelA = xgb.train({
    'eta': 1, 'max_depth': 3, 'base_score': 0, "lambda": 0
}, XdA, 1)
print(modelA.get_dump(with_stats=True)[0])

38.2 모델 B 생성

이는 모델 A의 원래 AND 기능 외에 자체적인 한계 효과가 있기 때문에 기침이 더 중요하다는 점을 제외하면 모델 A와 동일합니다.

yB = yA + X[:,1] * 10
# train a model with single tree
XdB = xgb.DMatrix(X, label=yB)
modelB = xgb.train({
    'eta': 1, 'max_depth': 3, 'base_score': 0, "lambda": 0
}, XdB, 1)
print(modelB.get_dump(with_stats=True)[0])

38.8 얻다

어떤 이유로 XGBoost는 Brieman, Friedman 및 기타 사람들이 고전적으로 제안한 것처럼 합산하는 대신 이득을 평균화합니다. 따라서 분할 횟수를 곱하여 평균을 취소합니다. (이득의 평균 버전도 일관성이 없지만 이 예에서는 그렇지 않습니다.)

38.9 순열

XGBoost는 권한 중요도를 구현하지 않으므로 직접 계산합니다.

def permute_importance(model, y):
    vals_fever = []
    Xtmp = X.copy()
    inds = list(range(Xtmp.shape[0]))
    for i in range(1000):
        np.random.shuffle(inds)
        Xtmp[:,0] = Xtmp[inds,0]
        err = y - model.predict(xgb.DMatrix(Xtmp))
        vals_fever.append(np.mean(np.sqrt(err*err)))
    
    vals_cough = []
    Xtmp = X.copy()
    inds = list(range(Xtmp.shape[0]))
    for i in range(1000):
        np.random.shuffle(inds)
        Xtmp[:,1] = Xtmp[inds,1]
        err = y - model.predict(xgb.DMatrix(Xtmp))
        vals_cough.append(np.mean(np.sqrt(err*err)))
    return np.mean(vals_fever),np.mean(vals_cough)
permuteA_fever,permuteA_cough = permute_importance(modelA, yA)
permuteA_fever,permuteA_cough
(19.99126498275, 19.98526500925)
permuteB_fever,permuteB_cough = permute_importance(modelB, yB)
permuteB_fever,permuteB_cough
(20.034424979099999, 25.004065000950632)
