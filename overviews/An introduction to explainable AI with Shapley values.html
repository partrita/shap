3  Shapley Value를 활용한 설명 가능한 AI(XAI) 입문

이 튜토리얼은 Shapley Value(샤플리 값)를 머신러닝 모델 해석에 활용하는 방법을 소개합니다. Shapley Value는 협동 게임 이론에서 유래된 개념으로, 각 요소에 기여도를 공정하게 배분하는 바람직한 속성을 가지고 있습니다. 본 가이드의 목적은 실제 머신러닝 모델에서 Shapley 기반의 기여도를 계산하고 해석하는 과정을 명확히 이해할 수 있도록 돕는 것입니다. shap 파이썬 패키지를 활용해 실습 위주의 접근 방식으로 점진적으로 복잡한 모델들을 해석해 나가는 과정을 살펴보겠습니다. 이 문서는 지속적으로 업데이트되는 가이드이며, shap 패키지의 공식 입문서 역할을 합니다. 피드백이나 기여를 원하신다면 언제든 이슈를 남겨주시거나 PR을 보내주세요!

3.1 선형 회귀 모델 설명

복잡한 모델을 설명하기 위해 Shapley 값을 사용하기 전에 이 값이 간단한 모델에서 어떻게 작동하는지 이해하는 것이 도움이 됩니다. 가장 간단한 모델 유형 중 하나는 표준 선형 회귀이므로 아래에서는 캘리포니아 주택 데이터 세트에서 선형 회귀 모델을 학습합니다. 이 데이터 세트는 1990년 캘리포니아 전역의 20,640개 주택 블록으로 구성되어 있으며, 여기서 우리의 목표는 8가지 다른 특성으로부터 중간 주택 가격의 자연 로그를 예측하는 것입니다.

  1. MedInc - 블록 그룹의 중간 소득
  2. HouseAge - 블록 그룹의 평균 주택 연령
  3. AveRooms - 가구당 평균 객실 수
  4. AveBedrms - 가구당 평균 침실 수
  5. 인구 - 블록 그룹 인구
  6. AveOccup - 평균 가구 구성원 수
  7. 위도 - 블록 그룹 위도
  8. 경도 - 블록 그룹 경도
import sklearn

import shap

# a classic housing price dataset
X, y = shap.datasets.california(n_points=1000)

X100 = shap.utils.sample(X, 100)  # 100 instances for use as the background distribution

# a simple linear model
model = sklearn.linear_model.LinearRegression()
model.fit(X, y)
LinearRegression()

3.1.1 모델 계수 조사

선형 모델을 이해하는 가장 일반적인 방법은 각 특성에 대해 학습된 계수를 조사하는 것입니다. 이러한 계수는 각 입력 특성을 변경할 때 모델 출력이 얼마나 변경되는지 알려줍니다.

print("Model coefficients:\n")
for i in range(X.shape[1]):
    print(X.columns[i], "=", model.coef_[i].round(5))
Model coefficients:

MedInc = 0.45769
HouseAge = 0.01153
AveRooms = -0.12529
AveBedrms = 1.04053
Population = 5e-05
AveOccup = -0.29795
Latitude = -0.41204
Longitude = -0.40125

계수는 입력 특성의 값을 변경할 때 어떤 일이 발생하는지 알려주는 데 유용하지만 그 자체로는 특성의 전반적인 중요성을 측정하는 좋은 방법이 아닙니다. 이는 각 계수의 값이 입력 특성의 규모에 따라 달라지기 때문입니다. 예를 들어 집의 나이를 연도가 아닌 분 단위로 측정한다면 HouseAge 기능의 계수는 0.0115 / (3652460) = 2.18e-8이 됩니다. 분명히 집이 지어진 지 연수는 분 수보다 중요하지 않지만 계수 값은 훨씬 더 큽니다. 이는 계수의 크기가 선형 모델에서 특성의 중요성을 나타내는 좋은 척도가 아닐 수도 있음을 의미합니다.

3.1.2 부분의존도를 사용한 보다 완전한 그림

모델에서 기능의 중요성을 이해하려면 해당 기능 변경이 모델 출력에 어떤 영향을 미치는지와 해당 기능 값의 분포를 모두 이해해야 합니다. 선형 모델에 대해 이를 시각화하기 위해 고전적인 부분 의존성 플롯을 작성하고 특성 값의 분포를 x축에 히스토그램으로 표시할 수 있습니다.

shap.partial_dependence_plot(
    "MedInc",
    model.predict,
    X100,
    ice=False,
    model_expected_value=True,
    feature_expected_value=True,
)

위 플롯의 회색 수평선은 캘리포니아 주택 데이터 세트에 적용될 때 모델의 예상 값을 나타냅니다. 회색 세로선은 중위소득 특성의 평균값을 나타냅니다. 파란색 부분 의존도 플롯 선(중간 소득 특성을 주어진 값으로 고정할 때 모델 출력의 평균 값)은 항상 두 개의 회색 기대 값 선의 교차점을 통과합니다. 이 교차점을 데이터 분포와 관련하여 부분 의존도 플롯의 “중심”으로 간주할 수 있습니다. 이 중심화의 영향은 다음에 Shapley 값을 살펴보면 명확해질 것입니다.

3.1.3 부분 의존도 플롯에서 SHAP 값 읽기

기계 학습 모델에 대한 Shapley 가치 기반 설명의 핵심 아이디어는 협력 게임 이론의 공정한 할당 결과를 사용하여 입력 기능 중 모델의 출력 \(f(x)\)에 대한 크레딧을 할당하는 것입니다. 게임 이론과 기계 학습 모델을 연결하려면 모델의 입력 특성을 게임 플레이어와 일치시키는 동시에 모델 기능을 게임 규칙과 일치시키는 것이 필요합니다. 게임 이론에서 플레이어는 게임에 참가하거나 참가하지 않을 수 있으므로 기능이 모델에 “참여”하거나 “참여하지 않는” 방법이 필요합니다. 특성이 모델에 “결합”된다는 것이 무엇을 의미하는지 정의하는 가장 일반적인 방법은 해당 특성의 값을 알고 있으면 해당 특성이 “모델에 합류”하고, 해당 특성의 값을 모르면 모델에 합류하지 않았다고 말하는 것입니다. 기능의 하위 집합 \(S\)만 모델의 일부인 경우 기존 모델 \(f\)를 평가하기 위해 조건부 기대값 공식을 사용하여 다른 기능을 통합합니다. 이 공식은 두 가지 형태를 취할 수 있습니다.

\[ E[f(X) \mid X_S = x_S] \]

or

\[ E[f(X) \mid do(X_S = x_S)] \]

첫 번째 형태에서는 S의 특징 값을 관찰하기 때문에 알 수 있습니다. 두 번째 형식에서는 S의 기능 값을 설정했기 때문에 알 수 있습니다. 일반적으로 두 번째 형식은 우리가 개입하여 입력을 변경할 경우 모델이 어떻게 작동할지 알려주고 계산하기가 훨씬 쉽기 때문에 일반적으로 선호됩니다. 이 튜토리얼에서는 전적으로 두 번째 공식에 중점을 둘 것입니다. 또한 기계 학습 모델의 조건부 기대 함수에 적용되는 Shapley 값을 나타내기 위해 보다 구체적인 용어인 “SHAP 값”을 사용합니다.

SHAP 값은 계산하기가 매우 복잡할 수 있지만(일반적으로 NP 하드임) 선형 모델은 매우 간단하여 부분 의존도 플롯에서 바로 SHAP 값을 읽을 수 있습니다. 예측 \(f(x)\)를 설명할 때 특정 기능 \(i\)에 대한 SHAP 값은 예상 모델 출력과 기능 값 \(x_i\)의 부분 의존도 플롯 간의 차이일 뿐입니다.

# compute the SHAP values for the linear model
explainer = shap.Explainer(model.predict, X100)
shap_values = explainer(X)

# make a standard partial dependence plot
sample_ind = 20
shap.partial_dependence_plot(
    "MedInc",
    model.predict,
    X100,
    model_expected_value=True,
    feature_expected_value=True,
    ice=False,
    shap_values=shap_values[sample_ind : sample_ind + 1, :],
)

고전적인 부분 의존도 플롯과 SHAP 값 사이의 긴밀한 대응은 전체 데이터 세트에서 특정 기능에 대한 SHAP 값을 플롯하면 해당 기능에 대한 부분 의존도 플롯의 평균 중심 버전을 정확하게 추적한다는 것을 의미합니다.

shap.plots.scatter(shap_values[:, "MedInc"])

3.1.4 샤플리 가치의 부가적 성격

Shapley 가치의 기본 속성 중 하나는 항상 모든 플레이어가 있을 때의 게임 결과와 플레이어가 없을 때의 게임 결과 간의 차이를 합산한다는 것입니다. 기계 학습 모델의 경우 이는 모든 입력 기능의 SHAP 값이 항상 기준(예상) 모델 출력과 설명 중인 예측에 대한 현재 모델 출력 간의 차이를 합산한다는 것을 의미합니다. 이를 확인하는 가장 쉬운 방법은 주택 가격 \(E[f(X)]\)에 대한 배경 사전 기대치에서 시작한 다음 현재 모델 출력 \(f(x)\)에 도달할 때까지 한 번에 하나씩 기능을 추가하는 폭포 플롯을 이용하는 것입니다.

# the waterfall_plot shows how we get from shap_values.base_values to model.predict(X)[sample_ind]
shap.plots.waterfall(shap_values[sample_ind], max_display=14)

3.2 가산 회귀 모델 설명

선형 모델의 부분 의존도가 SHAP 값과 긴밀하게 연결되어 있는 이유는 모델의 각 기능이 다른 모든 기능과 독립적으로 처리되기 때문입니다(효과는 함께 추가될 뿐입니다). 직선의 선형 요구 사항을 완화하면서 이러한 추가 특성을 유지할 수 있습니다. 그 결과 잘 알려진 종류의 일반화된 추가 모델(GAM)이 탄생합니다. 이러한 유형의 모델을 훈련하는 방법은 여러 가지가 있지만(예: XGBoost 모델을 깊이 1로 설정) 이를 위해 특별히 설계된 InterpretML의 설명 가능한 부스팅 머신을 사용하겠습니다.

# fit a GAM model to the data
import interpret.glassbox

model_ebm = interpret.glassbox.ExplainableBoostingRegressor(interactions=0)
model_ebm.fit(X, y)

# explain the GAM model with SHAP
explainer_ebm = shap.Explainer(model_ebm.predict, X100)
shap_values_ebm = explainer_ebm(X)

# make a standard partial dependence plot with a single SHAP value overlaid
fig, ax = shap.partial_dependence_plot(
    "MedInc",
    model_ebm.predict,
    X100,
    model_expected_value=True,
    feature_expected_value=True,
    show=False,
    ice=False,
    shap_values=shap_values_ebm[sample_ind : sample_ind + 1, :],
)
shap.plots.scatter(shap_values_ebm[:, "MedInc"])
# the waterfall_plot shows how we get from explainer.expected_value to model.predict(X)[sample_ind]
shap.plots.waterfall(shap_values_ebm[sample_ind])
# the beeswarm plot displays SHAP values for each feature across all examples,
# with colors indicating how the SHAP values correlate with feature values
shap.plots.beeswarm(shap_values_ebm)

# a classic adult census dataset price dataset

# a simple linear logistic model

model_adult.fit(X_adult, y_adult)


def model_adult_proba(x):
    return model_adult.predict_proba(x)[:, 1]


def model_adult_log_odds(x):
    p = model_adult.predict_log_proba(x)
    return p[:, 1] - p[:, 0]

이는 고도로 구조화된 입력이 있는 복잡한 모델 유형에 SHAP를 적용하는 방법을 보여줍니다.

import datasets
import numpy as np
import scipy as sp
import torch
import transformers

# load a BERT sentiment analysis model
tokenizer = transformers.DistilBertTokenizerFast.from_pretrained("distilbert-base-uncased")
model = transformers.DistilBertForSequenceClassification.from_pretrained(
    "distilbert-base-uncased-finetuned-sst-2-english"
).cuda()


# define a prediction function
def f(x):
    tv = torch.tensor([tokenizer.encode(v, padding="max_length", max_length=500, truncation=True) for v in x]).cuda()
    outputs = model(tv)[0].detach().cpu().numpy()
    scores = (np.exp(outputs).T / np.exp(outputs).sum(-1)).T
    val = sp.special.logit(scores[:, 1])  # use one vs rest logit units
    return val


# build an explainer using a token masker
explainer = shap.Explainer(f, tokenizer)

# explain the model's predictions on IMDB reviews
imdb_train = datasets.load_dataset("imdb")["train"]
shap_values = explainer(imdb_train[:10], fixed_context=1, batch_size=2)
