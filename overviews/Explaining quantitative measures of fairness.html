49  공정성의 정량적 척도를 설명

이 실습 기사에서는 설명 가능한 AI 방법을 공정성 측정과 연결하고 최신 설명 방법이 정량적 공정성 지표의 유용성을 어떻게 향상시킬 수 있는지 보여줍니다. SHAP(인기 설명 가능한 AI 도구)를 사용하여 공정성 측정을 분해하고 각 모델의 입력 특성 간에 관찰된 불일치에 대한 책임을 할당할 수 있습니다. 이러한 정량적 공정성 측정항목을 설명하면 이를 불투명한 공정성 표준으로 의존하는 경향을 줄일 수 있으며, 대신 모델 동작이 그룹 간에 어떻게 다른지 이해하기 위한 도구로 정보에 입각한 사용을 촉진할 수 있습니다.

정량적 공정성 측정항목은 기계 학습의 공정성 정의에 수학적 정확성을 부여하려고 합니다[1]. 그러나 공정성에 대한 정의는 인간의 윤리적 원칙에 깊이 뿌리를 두고 있으며, 기계 학습 모델이 사용되는 맥락에 따라 결정적으로 의존하는 가치 판단에도 뿌리를 두고 있습니다. 가치 판단에 대한 이러한 실질적인 의존성은 때로는 상호 양립할 수 없는 공정성 정의 간의 일련의 절충으로서 정량적 공정성 측정 수학에서 나타납니다[2]. 공정성은 상황에 따른 가치 판단에 의존하기 때문에 정량적 공정성 척도를 공정성에 대한 불투명한 블랙박스 척도로 취급하는 것은 위험합니다. 그렇게 하면 중요한 가치 판단 선택이 모호해질 수 있기 때문입니다.

49.1 모델 공정성의 다양한 측정을 설명하기 위해 SHAP를 사용하는 방법

이 문서에서는 모델 공정성의 “올바른” 척도를 선택하는 방법에 관한 것이 아니라 선택한 측정항목에 대해 설명합니다. 어떤 공정성 측정 기준이 가장 적합한지는 적용되는 법률, 기계 학습 모델의 출력이 사람들에게 미치는 영향, 다양한 결과에 부여하는 가치 및 이에 따른 상충 관계 등 상황의 구체적인 사항에 따라 달라집니다. 여기에서는 간단하고 이질적 영향에 대한 법적 개념과 밀접하게 연결되어 있는 고전적인 인구통계학적 동등성 측정항목을 사용하겠습니다. 동일한 분석을 의사결정 이론 비용, 균등 배당률, 균등한 기회와 같은 다른 측정항목에도 적용할 수 있습니다. 또는 동등한 서비스 품질. 인구통계학적 패리티는 기계 학습 모델의 출력이 두 개 이상의 그룹 간에 동일해야 함을 나타냅니다. 인구통계학적 패리티 차이는 두 샘플 그룹의 모델 결과 간에 얼마나 많은 차이가 있는지를 측정한 것입니다.

SHAP는 모델 출력을 원래 모델 출력과 동일한 단위를 사용하는 특성 속성으로 분해하므로 먼저 SHAP를 사용하여 각 입력 특성 간에 모델 출력을 분해한 다음 해당 특성에 대한 SHAP 값을 사용하여 각 입력 특성에 대한 인구통계학적 패리티 차이(또는 기타 공정성 측정항목)를 별도로 계산할 수 있습니다. SHAP 값이 모델의 출력에 합산되기 때문에 SHAP 값의 인구통계학적 패리티 차이의 합도 인구통계학적으로 합산됩니다. 전체 모델의 패리티 차이.

49.2 다양한 시뮬레이션 시나리오에서 SHAP 공정성 설명은 어떻게 되나요?

정량적 공정성 지표를 설명하는 잠재적인 유용성을 탐색하는 데 도움이 되도록 신용 인수를 기반으로 한 간단한 시뮬레이션 시나리오를 고려합니다. 우리의 시뮬레이션에는 대출 불이행 위험을 높이는 네 가지 기본 요소, 즉 소득 안정성, 소득 금액, 지출 제한, 일관성이 있습니다. 이러한 기본 요소는 관찰되지 않지만 관찰 가능한 네 가지 특징, 즉 직업 이력, 보고된 소득, 신용 조회 및 연체금에 다양하게 영향을 미칩니다. 이 시뮬레이션을 사용하여 무작위 샘플을 생성한 다음 비선형 XGBoost 분류기를 훈련하여 부도 확률을 예측합니다. SHAP에서 지원하는 다른 모델 유형에도 동일한 프로세스가 적용됩니다. 더 복잡한 모델에 대한 설명은 모델의 세부 사항을 더 많이 숨긴다는 점을 기억하세요.

완전히 지정된 시뮬레이션에 성별 보고 오류를 도입함으로써 이러한 오류로 인한 편견이 선택한 공정성 측정 기준에 의해 어떻게 포착되는지 관찰할 수 있습니다. 시뮬레이션된 사례에서 실제 레이블(대출 불이행)은 성별(공정성을 확인하는 데 사용하는 민감한 클래스)과 통계적으로 독립적입니다. 따라서 남성과 여성 간의 차이는 특성 측정 오류, 라벨링 오류 또는 모델 오류로 인해 하나 또는 두 그룹이 잘못 모델링되었음을 의미합니다. 예측하는 실제 레이블(액세스할 수 있는 훈련 레이블과 다를 수 있음)이 고려 중인 민감한 기능과 통계적으로 독립적이지 않은 경우 오류가 없는 완벽한 모델이라도 인구통계학적 패리티에 실패합니다. 이러한 경우 공정성 설명은 인구통계학적 불균형의 어떤 원인이 유효한지 판단하는 데 도움이 될 수 있습니다.

# here we define a function that we can call to execute our simulation under
# a variety of different alternative scenarios
import numpy as np
import pandas as pd

import shap

%config InlineBackend.figure_format = 'retina'


def run_credit_experiment(
    N,
    job_history_sex_impact=0,
    reported_income_sex_impact=0,
    income_sex_impact=0,
    late_payments_sex_impact=0,
    default_rate_sex_impact=0,
    include_brandx_purchase_score=False,
    include_sex=False,
):
    np.random.seed(0)
    sex = np.random.randint(0, 2, N) == 1  # randomly half men and half women

    # four hypothetical causal factors influence customer quality
    # they are all scaled to the same units between 0-1
    income_stability = np.random.rand(N)
    income_amount = np.random.rand(N)
    if income_sex_impact > 0:
        income_amount -= income_sex_impact / 90000 * sex * np.random.rand(N)
        income_amount -= income_amount.min()
        income_amount /= income_amount.max()
    spending_restraint = np.random.rand(N)
    consistency = np.random.rand(N)

    # intuitively this product says that high customer quality comes from simultaneously
    # being strong in all factors
    customer_quality = income_stability * income_amount * spending_restraint * consistency

    # job history is a random function of the underlying income stability feature
    job_history = np.maximum(
        10 * income_stability + 2 * np.random.rand(N) - job_history_sex_impact * sex * np.random.rand(N),
        0,
    )

    # reported income is a random function of the underlying income amount feature
    reported_income = np.maximum(
        10000
        + 90000 * income_amount
        + np.random.randn(N) * 10000
        - reported_income_sex_impact * sex * np.random.rand(N),
        0,
    )

    # credit inquiries is a random function of the underlying spending restraint and income amount features
    credit_inquiries = np.round(6 * np.maximum(-spending_restraint + income_amount, 0)) + np.round(
        np.random.rand(N) > 0.1
    )

    # credit inquiries is a random function of the underlying consistency and income stability features
    late_payments = np.maximum(
        np.round(3 * np.maximum((1 - consistency) + 0.2 * (1 - income_stability), 0))
        + np.round(np.random.rand(N) > 0.1)
        - np.round(late_payments_sex_impact * sex * np.random.rand(N)),
        0,
    )

    # bundle everything into a data frame and define the labels based on the default rate and customer quality
    X = pd.DataFrame(
        {
            "Job history": job_history,
            "Reported income": reported_income,
            "Credit inquiries": credit_inquiries,
            "Late payments": late_payments,
        }
    )
    default_rate = 0.40 + sex * default_rate_sex_impact
    y = customer_quality < np.percentile(customer_quality, default_rate * 100)

    if include_brandx_purchase_score:
        brandx_purchase_score = sex + 0.8 * np.random.randn(N)
        X["Brand X purchase score"] = brandx_purchase_score

    if include_sex:
        X["Sex"] = sex + 0

    # build model
    import xgboost

    model = xgboost.XGBClassifier(max_depth=1, n_estimators=500, subsample=0.5, learning_rate=0.05)
    model.fit(X, y)

    # build explanation
    import shap

    explainer = shap.TreeExplainer(model, shap.sample(X, 100))
    shap_values = explainer.shap_values(X)

    return shap_values, sex, X, explainer.expected_value

49.3 시나리오 A: 보고 오류 없음

첫 번째 실험은 성별에 따른 보고 오류가 발생하지 않도록 하는 간단한 기준 점검입니다. 인구통계학적 패리티를 측정하기 위해 모든 모델 출력을 사용할 수 있지만 이진 XGBoost 분류기의 연속 로그 확률 점수를 사용합니다. 예상한 대로, 이 기본 실험에서는 남성과 여성의 신용 점수 간에 인구통계학적 동등성 차이가 크게 나타나지 않았습니다. 여성과 남성의 평균 신용 점수 간의 차이를 막대 그래프로 표시하고 0이 오차 한계에 가깝다는 점을 참고하면 이를 확인할 수 있습니다(음수 값은 여성이 남성보다 평균 예측 위험이 낮다는 것을 의미하고 양수 값은 여성이 남성보다 평균 예측 위험이 더 높다는 것을 의미합니다).

N = 10000
shap_values_A, sex_A, X_A, ev_A = run_credit_experiment(N)

xmin = -0.8
xmax = 0.8
shap.group_difference_plot(shap_values_A.sum(1), sex_A, xmin=xmin, xmax=xmax, xlabel=glabel)

이제 SHAP를 사용하여 모델의 각 입력 기능 간에 모델 출력을 분해한 다음 각 기능에 귀속되는 구성 요소의 인구통계학적 패리티 차이를 계산할 수 있습니다. 위에서 언급한 것처럼 SHAP 값은 모델의 출력에 합산되므로 각 기능에 대한 SHAP 값의 인구통계학적 패리티 차이의 합은 전체 모델의 인구통계학적 패리티 차이와 합산됩니다. 이는 아래 막대의 합이 위 막대(기본 시나리오 모델의 인구통계학적 패리티 차이)와 같음을 의미합니다.

shap.group_difference_plot(shap_values_A, sex_A, X_A.columns, xmin=xmin, xmax=xmax, xlabel=slabel)

49.4 시나리오 B: 여성 소득에 대한 과소 보고 편향

기본 시나리오에서 우리는 성별이 모델에서 사용되는 기능이나 레이블에 영향을 미치지 않는 시뮬레이션을 설계했습니다. 여기 시나리오 B에서는 시뮬레이션에 여성 소득에 대한 과소보고 편향을 도입합니다. 여기서 중요한 점은 현실 세계에서 여성의 소득이 과소보고되는 것이 얼마나 현실적인가가 아니라, 성별에 따른 편견이 도입되었음을 어떻게 식별하고 그것이 어디서 왔는지 이해할 수 있는지입니다. 여성과 남성 사이의 평균 모델 결과(부도 위험)의 차이를 표시함으로써 우리는 소득을 과소 보고하는 편향으로 인해 여성이 남성보다 채무 불이행 위험이 더 높은 상당한 인구학적 동등성 차이가 발생했음을 알 수 있습니다.

SHAP 공정성 설명만을 사용하여 이 두 가지 상황 중 어느 것이 발생하고 있는지 판단하는 것은 불가능합니다. 두 경우 모두 보고된 소득 특성이 남성과 여성의 예상 위험 사이에 관찰된 불일치에 대한 책임이 있기 때문입니다.

여성의 채무불이행률에 대해 과소보고 편향을 도입했을 때 인구통계학적 동등성 차이가 발생하지 않았다는 사실이 처음에는 놀랄 수도 있습니다. 이는 시뮬레이션의 네 가지 기능 중 어느 것도 성별과 유의미한 상관관계가 없기 때문에 훈련 라벨에 도입한 편향을 모델링하는 데 효과적으로 사용할 수 없기 때문입니다. 대신 성별과 상관관계가 있는 새로운 기능(브랜드 X 구매 점수)을 모델에 제공하면 해당 기능이 모델에서 훈련 라벨의 성별별 편향을 포착하는 데 사용되므로 인구통계학적 동등성 차이가 나타나는 것을 볼 수 있습니다.

49.8 시나리오 F: 여러 가지 과소보고 편향 분리

보고 편향의 단일 원인이 있는 경우 모델 출력에 대한 고전적인 인구통계학적 패리티 테스트와 인구통계학적 패리티 테스트에 대한 SHAP 설명은 모두 동일한 편향 효과를 포착합니다(단, SHAP 설명은 편향을 유발하는 기능을 격리하므로 통계적으로 더 큰 의미를 가질 수 있는 경우가 많습니다). 하지만 데이터 세트에서 편향이 발생하는 여러 가지 원인이 있는 경우 어떻게 될까요? 이 실험에서 우리는 두 가지 편향, 즉 여성의 채무불이행률을 과소보고하는 것과 여성의 직업 이력을 과소보고하는 것을 소개합니다. 이러한 편향은 글로벌 평균에서 서로 상쇄되는 경향이 있으므로 모델 출력에 대한 인구통계학적 패리티 테스트에서는 측정 가능한 차이가 표시되지 않습니다.

49.9 보호된 기능을 도입하면 라벨 편향과 기능 편향을 구별하는 데 어떻게 도움이 됩니까?

시나리오 F에서 우리는 두 가지 형태의 편향을 구분할 수 있었습니다. 하나는 직업 이력을 과소보고하고 다른 하나는 부도율을 과소보고하는 것입니다. 그러나 기본율 과소보고로 인한 편향은 기본율 레이블에 기인한 것이 아니라 성별과 상관관계가 있는 브랜드 X 구매 점수 기능에 기인한 것입니다. 입력 특성으로 인한 차이는 해당 특성의 문제로 인한 것일 수도 있고 훈련 레이블의 문제로 인한 것일 수도 있기 때문에 이로 인해 인구통계학적 패리티 차이의 실제 원인에 대해 여전히 약간의 불확실성이 남아 있습니다.

이 경우 성별을 모델에 직접 변수로 도입하여 특성 편향에서 라벨 편향을 분리하는 데 도움이 될 수 있습니다. 입력 특성으로 성별을 도입하는 목적은 레이블 편향이 전적으로 성 특성에 속하게 하고 특성 편향은 그대로 유지하는 것입니다. 따라서 위의 시나리오 F의 결과를 아래의 새로운 시나리오 G와 비교하여 레이블 편향과 기능 편향을 구별할 수 있습니다. 물론 이는 이전보다 훨씬 더 강력한 인구통계학적 동등성 차이를 만들어내지만, 여기서 우리의 목표는 편견 완화가 아니라 오히려 편견 이해이기 때문에 괜찮습니다.

shap_values_G, sex_G, X_G, ev_G = run_credit_experiment(
    N,
    default_rate_sex_impact=-0.1,
    include_brandx_purchase_score=True,
    job_history_sex_impact=2,
    include_sex=True,
)
model_outputs_G = ev_G + shap_values_G.sum(1)
shap.group_difference_plot(shap_values_G.sum(1), sex_G, xmin=xmin, xmax=xmax, xlabel=glabel)
 97%|=================== | 9720/10000 [00:11<00:00]

시나리오 G에 대한 SHAP 설명은 시나리오 F에서 브랜드 X 구매 점수 기능에 첨부되었던 모든 인구통계학적 패리티 차이가 이제 성별 기능으로 이동한 반면, 시나리오 F의 직업 이력 기능에 첨부된 인구통계학적 패리티 차이는 전혀 이동하지 않았음을 보여줍니다. 이는 시나리오 F에서 브랜드 X 구매 점수로 인한 모든 차이는 라벨 편향으로 인한 반면, 시나리오 F에서 작업 이력으로 인한 모든 차이는 기능 편향으로 인한 것임을 의미하는 것으로 해석될 수 있습니다.

49.10 결론

공정성은 깨끗한 수학적 답변이 거의 항상 경고와 함께 제공되고 윤리적 가치 판단에 의존하는 복잡한 주제입니다. 이는 공정성 지표를 블랙박스로 사용하는 것뿐만 아니라 이러한 지표가 계산되는 방식과 모델 및 교육 데이터의 어떤 측면이 관찰된 불균형에 영향을 미치는지 이해하는 것이 특히 중요하다는 것을 의미합니다. SHAP를 사용하여 정량적 공정성 메트릭을 분해하면 메트릭이 몇 가지 기능에만 영향을 미치는 측정 편향에 의해 구동될 때 불투명도를 줄일 수 있습니다. 여기서 설명한 공정성 설명이 공정성 평가에 내재된 기본 가치 판단과 더 잘 씨름하고 실제 상황에서 공정성 지표를 사용할 때 발생하는 의도하지 않은 결과의 위험을 줄이는 데 도움이 되기를 바랍니다.
