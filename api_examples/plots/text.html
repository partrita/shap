88  텍스트 플롯

이 노트북은 shap.plots.text 기능을 사용하는 방법을 시연하고 문서화하기 위해 설계되었습니다. IMDB 영화 리뷰에 대한 감정 분석을 수행하기 위해 Transformers 패키지의 증류된 PyTorch BERT 모델을 사용합니다.

우리가 정의한 예측 함수는 문자열 목록을 가져와서 양성 클래스에 대한 로짓 값을 반환합니다.

import nlp
import numpy as np
import scipy as sp
import torch
import transformers

import shap

# load a BERT sentiment analysis model
tokenizer = transformers.DistilBertTokenizerFast.from_pretrained("distilbert-base-uncased")
model = transformers.DistilBertForSequenceClassification.from_pretrained(
    "distilbert-base-uncased-finetuned-sst-2-english"
).cuda()


# define a prediction function
def f(x):
    tv = torch.tensor([tokenizer.encode(v, padding="max_length", max_length=500, truncation=True) for v in x]).cuda()
    outputs = model(tv)[0].detach().cpu().numpy()
    scores = (np.exp(outputs).T / np.exp(outputs).sum(-1)).T
    val = sp.special.logit(scores[:, 1])  # use one vs rest logit units
    return val


# build an explainer using a token masker
explainer = shap.Explainer(f, tokenizer)

# explain the model's predictions on IMDB reviews
imdb_train = nlp.load_dataset("imdb")["train"]
shap_values = explainer(imdb_train[:10], fixed_context=1)

88.1 단일 인스턴스 텍스트 플롯

단일 인스턴스를 텍스트 플롯에 전달하면 해당 토큰에 해당하는 원본 텍스트에 오버레이된 각 토큰의 중요성을 얻게 됩니다. 빨간색 영역은 포함된 경우 모델의 출력을 높이는 텍스트 부분에 해당하고, 파란색 영역은 포함된 경우 모델의 출력을 감소시킵니다. 감정 분석 모델의 맥락에서 빨간색은 보다 긍정적인 리뷰에 해당하고 파란색은 보다 부정적인 리뷰에 해당합니다.

텍스트 모델에 대해 반환된 중요도 값은 계층적이며 텍스트 구조를 따르는 경우가 많습니다. 토큰 그룹 간의 비선형 상호 작용은 종종 저장되며 플로팅 프로세스 중에 사용될 수 있습니다. 텍스트 플롯에 전달된 설명 객체에 .hierarchical_values 속성이 있는 경우 강력한 비선형 효과가 있는 작은 토큰 그룹이 자동으로 병합되어 일관된 덩어리를 형성합니다. .hierarchical_values 속성이 존재하는 경우 설명자가 가능한 모든 토큰 변동을 완전히 열거하지 않았을 수 있으므로 텍스트 덩어리를 본질적으로 단일 단위로 처리했음을 의미합니다. 이는 문서에 있는 토큰 수보다 적은 횟수로 텍스트 모델을 평가하면서 텍스트 모델을 설명하려는 경우가 많기 때문에 발생합니다. 입력 텍스트의 영역이 설명자에 의해 분할되지 않을 때마다 텍스트 플롯에 단일 단위로 표시됩니다.

텍스트 위의 힘 플롯은 텍스트의 모든 부분이 결합되어 모델의 출력을 생성하는 방법에 대한 개요를 제공하도록 설계되었습니다. 자세한 내용은 force 플롯 노트북을 참조하세요. 그러나 플롯의 일반적인 구조는 양의 빨간색 기능이 모델 출력을 더 높게 “밀어내는” 반면 음의 파란색 기능은 모델 출력을 더 낮게 “밀어내는” 것입니다. 힘 플롯은 텍스트 색상보다 훨씬 더 많은 정량적 정보를 제공합니다. 텍스트 척 위로 마우스를 가져가면 해당 텍스트 덩어리에 해당하는 힘 플롯 부분에 밑줄이 표시되고, 힘 플롯 부분 위로 마우스를 가져가면 해당 텍스트 덩어리에 밑줄이 표시됩니다.

텍스트 덩어리를 클릭하면 해당 덩어리의 토큰에 귀속된 SHAP 값의 합계가 표시됩니다(다시 클릭하면 값이 숨겨집니다).

# plot the first sentence's explanation
shap.plots.text(shap_values[3])

텍스트 플롯을 사용하여 여러 인스턴스 수준 설명을 그리는 것은 매우 유익할 수 있지만 때로는 대규모 인스턴스 집합에 대한 토큰의 영향에 대한 전역 요약을 원할 수도 있습니다. 자세한 내용은 설명 객체 문서를 참조하세요. 그러나 다중 행 설명 객체를 모든 행에 걸쳐 축소하여(이 경우 합산을 통해) 데이터세트에서 토큰의 중요성을 쉽게 요약할 수 있습니다. 이렇게 하면 모든 텍스트 입력 토큰 유형이 기능으로 처리되므로 축소된 설명 개체는 원래 다중 행 설명 개체에 있었던 고유 토큰만큼 많은 열을 갖게 됩니다. 설명 개체에 계층적 값이 있는 경우 큰 그룹은 나누어지고 그룹의 각 토큰에는 전체 그룹 중요도 값의 동일한 공유가 제공됩니다.

shap.plots.bar(shap_values.abs.sum(0))

기능의 중요성을 어떻게 요약하느냐에 따라 큰 차이가 생길 수 있습니다. 위의 플롯에서 ‘a’ 토큰은 모델에 영향을 미치고 매우 일반적이기 때문에 매우 중요했습니다. 아래에서는 ‘max’ 함수를 사용하여 인스턴스를 요약하여 모든 인스턴스에서 토큰의 가장 큰 영향을 확인합니다.

shap.plots.bar(shap_values.abs.max(0))

해당 토큰을 입력 이름으로 사용하여 모든 인스턴스에서 단일 토큰을 분할할 수도 있습니다. 입력 이름 왼쪽의 회색 값은 토큰이 생성된 원본 텍스트입니다.

shap.plots.bar(shap_values[:, "but"])
shap.plots.bar(shap_values[:, "but"])

88.4 텍스트-텍스트 시각화

from transformers import AutoModelForSeq2SeqLM, AutoTokenizer

import shap

tokenizer = AutoTokenizer.from_pretrained("Helsinki-NLP/opus-mt-en-es")
model = AutoModelForSeq2SeqLM.from_pretrained("Helsinki-NLP/opus-mt-en-es").cuda()

s = ["In this picture, there are four persons: my father, my mother, my brother and my sister."]

explainer = shap.Explainer(model, tokenizer)

shap_values = explainer(s)

텍스트-텍스트 시각화에는 왼쪽에 모델에 대한 입력 텍스트가 포함되고 오른쪽에 출력 텍스트가 포함됩니다(기본 레이아웃). 오른쪽(출력)에 있는 토큰 위로 마우스를 가져가면 각 입력 토큰의 중요성이 오버레이되고 토큰의 배경색으로 표시됩니다. 빨간색 영역은 포함된 경우 모델의 출력을 높이는 텍스트 부분에 해당하고, 파란색 영역은 포함된 경우 모델의 출력을 감소시킵니다. 특정 출력 토큰에 대한 설명은 출력 토큰을 클릭하여 고정할 수 있습니다(다시 클릭하면 고정 해제 가능).

위에서 설명한 단일 출력 플롯과 유사하게 텍스트 모델에 대해 반환된 중요도 값은 계층적이며 텍스트 구조를 따르는 경우가 많습니다. 강력한 비선형 효과를 지닌 소규모 토큰 그룹은 자동으로 병합되어 일관된 덩어리를 형성합니다. 마찬가지로 설명자는 가능한 모든 토큰 섭동을 완전히 열거하지 않았을 수 있으므로 텍스트 덩어리를 본질적으로 단일 단위로 처리했습니다. 이 전처리는 각 출력 토큰에 대해 수행되며, 각 출력 토큰마다 상호작용 효과가 다를 수 있으므로 병합 동작은 각 출력 토큰마다 다를 수 있습니다. 출력 토큰이 고정되면 입력 텍스트 위로 마우스를 가져가면 병합된 청크를 볼 수 있습니다. 병합된 청크의 모든 토큰은 굵게 표시됩니다.

출력 텍스트가 고정되면 입력 토큰을 클릭하여 정확한 모양 값을 볼 수 있습니다(입력 토큰 위로 마우스를 가져가면 값이 포함된 도구 설명도 표시됩니다). 자동 병합된 토큰은 총 값을 해당 청크의 토큰 수로 나눈 값을 표시합니다.

입력 텍스트 위로 마우스를 가져가면 각 출력 토큰에 대한 해당 토큰의 SHAP 값이 표시됩니다. 이는 출력 토큰의 배경색으로 다시 나타납니다. 이는 입력 토큰을 클릭하여 고정할 수 있습니다.

참고: 모든 토큰(입력 및 출력)의 색상 스케일링은 일관되며 가장 밝은 빨간색은 모든 출력 토큰에 대한 입력 토큰의 최대 SHAP 값에 할당됩니다.

참고: 두 텍스트의 레이아웃은 ‘레이아웃’ 드롭다운 메뉴를 사용하여 변경할 수 있습니다.

shap.plots.text(shap_values)
