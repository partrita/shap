45  Azure Cognitive Services 및 파티션 설명을 사용하여 이미지 캡션(이미지를 텍스트로) 설명

이 노트북은 이미지 캡션 모델의 출력을 설명하기 위해 SHAP를 사용하는 방법을 보여줍니다. 즉, 이미지가 주어지면 모델은 이미지에 대한 캡션을 출력합니다.

여기서는 COGS CV(Azure Cognitive Services Computer Vision) 이미지 이해(이미지 분석) 기능인 https://azure.microsoft.com/en-us/services/cognitive-services/computer-vision/#features를 사용하여 이미지 캡션을 가져옵니다.

45.0.1 제한사항

  1. 이미지 캡션을 설명하기 위해 축을 따라 이미지를 분할합니다(예: 슈퍼 픽셀/반쪽, 4분의 1, 8개의 파티션…). 대체 접근 방식/향후 개선 방법은 축 정렬 분할 대신 이미지를 의미론적으로 분할하고 슈퍼 픽셀 대신 세그먼트를 사용하여 SHAP 설명을 생성하는 것입니다. https://github.com/shap/shap/issues/1738

  2. 외부 모델이 원래 캡션 모델의 언어 헤드에 대한 좋은 대리자라고 가정하고 변환기 언어 모델(예: distilbart)을 사용하여 주어진 이미지와 마스크된 이미지 캡션 간의 정렬 채점을 수행합니다. 캡션 모델의 자체 언어 헤드를 사용하여 이러한 가정을 제거하고 종속성을 제거할 수 있습니다. (예: text2text 노트북 예시 참조) 자세한 내용은 아래 “언어 모델 및 토크나이저 로드” 섹션을 참조하세요. https://github.com/shap/shap/issues/1739

  3. 여기서는 Azure Cognitive Service를 사용하여 이미지 캡션을 가져옵니다. API 호출에는 속도 제한이 없으므로 더 빠르게 설명을 받으려면 유료 서비스를 이용하세요. 가격 세부 정보는 https://azure.microsoft.com/en-us/pricing/details/cognitive-services/computer-vision/에서 확인할 수 있습니다.

  4. Azure Cognitive Service에는 이미지 크기 및 파일 형식에 대한 특정 크기 제한이 있습니다. API 세부 정보는 https://westcentralus.dev.cognitive.microsoft.com/docs/services/computer-vision-v3-1-ga/Operations/56f91f2e778daf14a499f21b에서 확인할 수 있습니다. 자세한 내용은 “데이터 로드” 섹션을 참조하세요.

  5. 큰 이미지는 SHAP 설명 생성 속도를 느리게 합니다. 따라서 크기가 500픽셀보다 큰 이미지는 크기가 조정됩니다. 자세한 내용은 “데이터 로드” 섹션을 참조하세요.

  6. 설명을 생성하는 데 사용되는 평가가 많을수록 SHAP를 실행하는 데 더 오랜 시간이 걸립니다. 그러나 평가 수를 늘리면 설명의 세분성이 높아집니다(300~500개의 평가는 종종 자세한 지도를 생성하지만 그보다 적거나 그 이상이 합리적인 경우도 많습니다). 자세한 내용은 아래의 “래핑된 모델 및 이미지 마스커를 사용하여 설명 개체 만들기” 섹션을 참조하세요.

45.0.2 API 세부정보

Azure COGS CV를 사용하고 이 노트북을 실행하려면 Azure COGS CV 구독과 관련된 API 키와 엔드포인트를 가져와 <> 아래 코드로 바꾸세요. API 호출에 대한 요금 제한을 피하고 설명을 빠르게 받으려면 무료 서비스보다 유료 서비스를 받는 것이 좋습니다.

# place your Azure COGS CV subscription API Key and Endpoint below
API_KEY = "<your COGS API access key>"
ENDPOINT = "<endpoint specific to your subscription>"

ANALYZE_URL = ENDPOINT + "/vision/v3.1/analyze"
def get_caption(path_to_image):
    """Function to get image caption when path to image file is given.
    Note: API_KEY and ANALYZE_URL need to be defined before calling this function.

    Parameters
    ----------
    path_to_image   : path of image file to be analyzed

    Output
    -------
    image caption

    """
    headers = {
        "Ocp-Apim-Subscription-Key": API_KEY,
        "Content-Type": "application/octet-stream",
    }
    params = {
        "visualFeatures": "Description",
        "language": "en",
    }

    payload = open(path_to_image, "rb").read()

    # get image caption using requests
    response = requests.post(ANALYZE_URL, headers=headers, params=params, data=payload)
    results = json.loads(response.content)

    # return the first caption's text in results description
    caption = results["description"]["captions"][0]["text"]

    return caption

45.0.3 데이터 로드

‘./test_images/’는 설명할 이미지 폴더입니다.’./test_images/’ 디렉토리가 생성되었으며 노트북에 표시된 예제를 복제하는 데 필요한 샘플 이미지가 이미 디렉토리에 배치되어 있습니다.

45.0.3.0.1 Azure COGS CV 이미지 요구 사항:

  1. 이미지 캡션에 대한 설명을 얻으려면 현재 노트북 작업 디렉터리의 ’test_images’라는 폴더에 설명할 이미지를 배치하세요.

  2. Azure COGS CV는 JPEG(JPG), PNG, GIF, BMP, JFIF 파일 형식의 이미지를 허용합니다.

  3. Azure COGS CV의 크기 제한은 4MB 미만이고 이미지의 최소 크기는 50x50입니다. 따라서 SHAP 설명 속도를 높이고 이미지 캡션을 위해 Azure COGS를 실행하기 위해 아래 코드에서 대용량 이미지 파일의 모양을 변경하고 있습니다. 이미지(pixel_size, pixel_size)가 두 크기 중 하나에서 500보다 큰 경우 이미지 크기가 최대 500으로 조정됩니다. 500보다 큰 치수의 경우 500픽셀 크기이고 다른 치수는 원래 종횡비를 유지하면서 크기가 조정됩니다.

참고: 모양이 변경된 이미지 캡션은 원본 이미지 캡션과 다를 수 있습니다. 원본 이미지에 대한 설명이 필요한 경우 아래의 ‘reshape’ 변수를 ’False’로 전환하세요. 그러나 이로 인해 설명 프로세스가 크게 느려지거나 Azure COGS CV가 캡션을 생성하지 못할 수 있습니다(SHAP는 이 이미지에 대한 설명을 생성할 수 없습니다).

# directory of images to be explained
DIR = "./test_images/"
# creates or empties directory if it already exists
make_dir(DIR)
add_sample_images(DIR)

# directory for saving resized images
DIR_RESHAPED = "./reshaped_images/"
make_dir(DIR_RESHAPED)

# directory for saving masked images
DIR_MASKED = "./masked_images/"
make_dir(DIR_MASKED)

45.0.5 언어 모델 및 토크나이저 로드

여기서는 Transformer Language Model ’distilbart’와 토크나이저를 사용하여 이미지 캡션을 토큰화합니다. 이는 이미지를 텍스트로 변환하는 시나리오를 다중 클래스 문제와 유사하게 만듭니다. ’distilbart’는 원본 이미지 캡션과 생성되는 마스크된 이미지 캡션 간의 정렬 채점을 수행하는 데 사용됩니다. 즉, 마스크된 이미지 캡션의 컨텍스트가 제공될 때 원본 이미지 캡션을 얻을 확률이 어떻게 변경됩니까? (즉, 우리는 ’distilbart’가 항상 마스크된 이미지에 대한 원본 이미지 캡션을 생성하도록 강제하고 프로세스의 일부로 캡션의 토큰화된 각 단어에 대한 로짓의 변경을 가져오는 교사입니다.)

참고: 실험 과정에서 이미지에 대해 가장 의미 있는 설명을 제공하는 것으로 나타났기 때문에 여기에서는 ‘distilbart’를 사용하고 있습니다. 우리는 ’openaigpt’ 및 ’distilgpt2’와 같은 다른 언어 모델과 비교했습니다. 원하는 다른 언어 모델을 자유롭게 탐색하고 결과를 비교해 보세요.

# load transformer language model and tokenizer

실험할 설명자 개체의 다양한 옵션:

  1. mask_value : 이미지 마스커는 기본적으로 마스킹에 인페인팅 기술을 사용합니다(예: 마스크_값 = “inpaint_ns”). “inpaint_telea” 및 “blur(kernel_xsize, kernel_xsize)”와 같은 흐림/인페인팅에 사용할 수 있는 대체 마스킹 옵션이 있습니다. 참고: 다양한 마스킹 옵션에 따라 다양한 설명이 생성될 수 있습니다.

  2. max_evals : SHAP 값을 얻기 위해 기본 모델에 대해 수행된 평가 횟수입니다. 슈퍼 픽셀의 의미 있는 세분성을 갖춘 설명을 얻으려면 권장되는 평가 횟수는 300~500회입니다. 평가 횟수가 많을수록 세분성이 높아지지만 런타임도 늘어납니다. 기본값은 평가 300개로 설정되어 있습니다.

  3. batch_size : 한 번에 평가할 마스크된 이미지 수입니다. 기본 크기는 50으로 설정되어 있습니다.

  4. fixed_context : ‘0’, ‘1’ 또는 ‘없음’ 옵션을 사용하여 파티션 트리를 구축하는 데 사용되는 마스킹 기술입니다. ’fixed_context = None’은 의미 있는 결과를 생성하는 가장 좋은 옵션이지만 전체 파티션 트리를 생성하기 때문에fixed_context = 0 또는 1보다 상대적으로 느립니다. 기본 옵션은 ’없음’으로 설정되어 있습니다.

# function to take a list of images and parameters such as masking option, max evals etc. and return shap_values objects
def run_masker(
    X,
    mask_value="inpaint_ns",
    max_evals=300,
    batch_size=50,
    fixed_context=None,
    show_grid_plot=False,
    limit_grid=20,
):
    """Function to take a list of images and parameters such max evals etc. and return shap explanations (shap_values) for test images(X).
    Paramaters
    ----------
    X               : list of images which need to be explained
    mask_value      : various masking options for blurring/inpainting such as "inpaint_ns", "inpaint_telea" and "blur(pixel_size, pixel_size)"
    max_evals       : number of evaluations done of the underlying model to get SHAP values
    batch_size      : number of masked images to be evaluated at once
    fixed_context   : masking technqiue used to build partition tree with options of '0', '1' or 'None'
    show_grid_plot  : if set to True, shows grid plot of all masked images and their captions used to generate SHAP values (default: False)
    limit_grid      : limit number of masked images shown (default:20). Change to "all" to show all masked_images.
    Output
    ------
    shap_values_list: list of shap_values objects generated for the images
    """
    global image_counter
    global mask_counter
    shap_values_list = []

    for index in range(len(X)):
        # define a masker that is used to mask out partitions of the input image based on mask_value option
        masker = shap.maskers.Image(mask_value, X[index].shape)

        # wrap model with TeacherForcingLogits class
        wrapped_model = shap.models.TeacherForcingLogits(f, similarity_model=model, similarity_tokenizer=tokenizer)

        # build a partition explainer with wrapped_model and image masker
        explainer = shap.Explainer(wrapped_model, masker)

        # compute SHAP values - here we use max_evals no. of evaluations of the underlying model to estimate SHAP values
        shap_values = explainer(
            np.array(X[index : index + 1]),
            max_evals=max_evals,
            batch_size=batch_size,
            fixed_context=fixed_context,
        )
        shap_values_list.append(shap_values)

        # output plot
        shap_values.output_names[0] = [word.replace("Ġ", "") for word in shap_values.output_names[0]]
        shap.image_plot(shap_values)

        # show grid plot of masked images and their captions
        if show_grid_plot:
            if limit_grid == "all":
                display_grid_plot(masked_captions[image_counter], masked_files[image_counter])
            elif isinstance(limit_grid, int) and limit_grid < len(masked_captions[image_counter]):
                display_grid_plot(
                    masked_captions[image_counter][0:limit_grid],
                    masked_files[image_counter][0:limit_grid],
                )
            else:
                print("Enter a valid number for limit_grid parameter.")

        # setting values for next iterations
        mask_counter = 0
        image_counter += 1

    return shap_values_list
